# openapi4s-demo

Petstore [spec](api/src/main/resources/public/openapi.json) is downloaded on 26.12.2024 from https://petstore3.swagger.io/api/v3/openapi.json

Here is a video demo: https://youtu.be/kf0vGrlKNb8

## Usage

Requires JDK 17 or newer and sbt 2 (pinned in `project/build.properties`).
The build uses sbt-openapi4s 0.1.0 and OpenAPI4s 0.9.1-SNAPSHOT (from the Sonatype snapshots repository), generating http4s routes and Circe models.
The server runs on http4s Ember.

```shell
# 1. update the openapi.json

# 2. (re)generate
sbt 'api/openApi4sGenerate; scalafmtAll'

# 3. see what changed
git diff

# 4. fill in the details
sbt 'api/compile'

# 5. git commit
```

By default, all endpoints will return 501 NotImplemented status.  
You just need to fill in the details. :) 

OpenApi4s will only overwrite definitions that it wrote originally (not the expressions though!).  
Any class/method/val generated by OpenApi4s can be overwritten if you change it manually!  
Other code (e.g. business logic in controller), *that you wrote* will not be touched. :)

Run the application with `sbt 'api/run'`.

## Swagger UI

Access it at http://localhost:8080/swagger

## CI check

There is a small chance that OpenApi4s overwrites your changes.  
To prevent that, there is a [small CI script](./.github/workflows/ci.yml) that checks this.  
It regenerates the files and checks that the generated sources have no changes afterward.
This way you can be sure that your changes are preserved correctly.

## Formatting and smoke tests

Formatting uses sbt-scalafmt 2.6.2 with Scalafmt 3.11.5 pinned in `.scalafmt.conf`.
The Scala 3 rewrites use [Scalafmt's common preset](https://scalameta.org/scalafmt/docs/configuration#rewritescala3-presets). Run `sbt scalafmtAll` after generation.

```shell
sbt scalafmtCheckAll
sbt 'api/Test/runMain com.example.petstore.HttpSmokeTest'
```

The smoke tests start an Ember server on an available port and check API stubs, JSON decoding errors, Swagger UI, static resources, and missing routes. The server is closed when the checks finish.
